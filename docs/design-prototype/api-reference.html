class SwarmQ

The application entrypoint — owns the broker connection, the backend pool, the middleware stack, and the signal dispatcher.

class SwarmQ(broker_url: str, backend_url: str, *, middleware: list[Middleware] | None = None, result_ttl: int = 3600)

A SwarmQ instance is both a client (for scheduling tasks) and the context a worker reads configuration from. Use it as an async context manager to ensure the broker connection and backend pool are closed cleanly.

Thread safety A single SwarmQ instance is safe to share across coroutines on the same event loop. Do not share it across processes — each process should build its own.

Methods

schedule()

async
async def schedule( task: type[Task], *args, delay: float | None = None, unique_key: str | None = None, **kwargs, ) -> TaskHandle

Enqueue a task for asynchronous execution. Returns a TaskHandle that can be awaited or polled for the final result.

Parameters

NameTypeDescription
task type[Task] The task class to schedule. Must be importable from the worker's --module.
*args, **kwargs Any Positional and keyword arguments forwarded to run(). Must be msgpack-serialisable.
delay float | None Delay in seconds before delivery. None (default) means deliver immediately.
unique_key str | None Dedup key. If a task with the same key is in-flight, this call returns the existing handle.

Returns

A TaskHandle — await handle.wait(timeout=...) to block until completion, or await handle.result() for fire-and-forget retrieval.

Raises

BrokerUnavailable if the broker connection drops during publish and reconnect fails. SerializationError if arguments are not msgpack-compatible.

Example

python 
handle = await app.schedule(
    SendEmail,
    to="alice@example.com",
    subject="Welcome",
    delay=30.0,
)
result = await handle.wait(timeout=60)

start_worker()

async
async def start_worker(queues: list[str], *, concurrency: int = 10) -> None

Start consuming from one or more queues. Returns when a shutdown signal arrives. The CLI's swarmq worker is a thin wrapper around this.

Parameters

queueslist[str]Queue names to consume from. Order defines priority on contention.
concurrencyintMaximum number of tasks running concurrently. Default 10.

on_signal()

decorator
def on_signal(signal: Signal) -> Callable

Register a coroutine handler for a lifecycle signal. Handlers are fire-and- forget from the worker's perspective; exceptions are caught and logged.

Example

python 
@app.on_signal(Signal.TASK_FAILURE)
async def record_failure(ctx, exc):
    await sentry.capture(exc, tags={"task": ctx.task_name})
