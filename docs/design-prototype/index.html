A task queue that gets out of your way.

Async-first Python tasks on RabbitMQ and Valkey. One command to run a worker, middleware and signals that compose, rate limits and retries that don't surprise you.

from swarmq.task import Task, TaskInfo

class SendEmail(Task):
    task_info = TaskInfo(
        name="send_email",
        queues=["default"],
        rate_limit="100/m",
        max_retries=3,
    )

Designed for production

Everything a real worker needs.

Retries, timeouts, rate limits, dead-letter routing, and observability are first-class — not bolted on after the fact.

At-least-once delivery

RabbitMQ-backed acks, retries with exponential, linear, or fixed backoff, DLQ routing on exhaustion.

Async from the core

Built on asyncio and aio-pika. Semaphore-bounded concurrency per worker, no thread hacks.

Middleware & signals

Six middleware hooks with stack semantics, fourteen lifecycle signals, and a @on_signal decorator.

Rate limiting

Sliding-window counters via Lua on Valkey. Declare "100/m", enforcement happens before execution.

Locks & dedup

Task-level mutex and semaphore, plus unique-task keys for idempotent scheduling.

One-command worker

swarmq worker --module myapp.tasks. Graceful SIGTERM drain, JSON logs for aggregators, no boilerplate.

Ready in five minutes.

Install via uv add swarmq, define a task class, run the worker. The Getting Started walks you through the full round-trip.
