usage: swarmq dlq list [-h] [--queue QUEUE] [--limit LIMIT]
                       [--format {table,json}]

Drain-and-republish scan of {queue}.XQ. Shows task_id, task_name, retry-count
header, traceback preview, and body size. Repeated calls are safe; messages
stay in the DLQ.

options:
  -h, --help            show this help message and exit
  --queue QUEUE         Main queue name (DLQ resolved as {queue}.XQ). Default:
                        default.
  --limit LIMIT         Max messages to list (default: 100).
  --format {table,json}
                        Output format. Default: 'table' on a TTY, 'json' on a
                        pipe. Override the default with
                        SWARMQ_DEFAULT_FORMAT=table|json.
