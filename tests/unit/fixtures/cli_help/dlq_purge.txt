usage: swarmq dlq purge [-h] [--queue QUEUE] [--format {table,json}]

Native AMQP queue.purge() on {queue}.XQ. Irreversible; messages are lost. Use
with care.

options:
  -h, --help            show this help message and exit
  --queue QUEUE         Main queue name (default: default).
  --format {table,json}
                        Output format. Default: 'table' on a TTY, 'json' on a
                        pipe. Override the default with
                        SWARMQ_DEFAULT_FORMAT=table|json.
