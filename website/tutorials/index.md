# Tutorials

Multi-step, hands-on walk-throughs. Each tutorial takes a newcomer
from zero to a working outcome — read front-to-back, type along,
expect every snippet to run unchanged.

Use the tutorials when you want to **learn by doing**. For a
targeted answer to a specific question, see the
[how-to guides](../guides/index.md). For the short round-trip, see
[Getting Started](../getting-started.md).

## Available

- [**Build your first email worker**](first-email-worker.md) — a
  full 45–60-minute walkthrough that builds a SendEmail task,
  adds retries and rate limits, observes lifecycle events through
  a signal handler, triggers a dead-letter route, and recovers it
  with the CLI.

## Where to go next

After finishing a tutorial, consolidate by reading one or two
[how-to guides](../guides/index.md) on the features you touched —
the guides have the parameter matrices the tutorial glossed over.
