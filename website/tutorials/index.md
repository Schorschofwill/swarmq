# Tutorials

Hands-on walkthroughs that take you from nothing to a working result.
Read them front to back and type along; every snippet runs as shown.

Tutorials are for **learning by doing**. For the five-minute round trip,
see [Getting Started](../getting-started.md); for answers to a specific
question, the [how-to guides](../guides/index.md).

## Available

- [**Build your first email worker**](first-email-worker.md) — about
  45 minutes. You build a `SendEmail` task, add retries and a rate
  limit, watch lifecycle events through signal handlers, send a message
  to the dead-letter queue and replay it with the CLI.

## Afterwards

Read the [how-to guides](../guides/index.md) for the features you
used: they list the options the tutorial leaves out.
